# Marlborough College Quantitative Finance Society

A student-run society for people interested in markets, quantitative problem solving,
and the mathematics behind both. We run portfolio and investment work, puzzle sessions,
stock pitches, and shared study resources — no prior finance experience required.

## What we do

- **Portfolio & investment policy** — building and maintaining an Investment Policy
  Statement, running a tracked portfolio, and logging every trade with a written rationale.
- **Puzzles** — Jane Street puzzles and similar quantitative brainteasers, written up
  properly so the reasoning is reusable.
- **Stock pitches** — members research a company and present a thesis, slides and all.
- **Study & preparation** — reading lists, TMUA materials, and shared notes.
- **Tools** — code written by members: backtests, scrapers, pricing models, utilities.
- **Leaderboard** — standings across puzzles, pitches, and participation, updated weekly.

## Repository layout

| Folder | Contents |
| --- | --- |
| `logs/` | One markdown file per session, named by date (`YYYY-MM-DD.md`). |
| `wharton/` | IPS drafts, research notes, portfolio tracker, trade log. |
| `puzzles/` | Jane Street puzzle write-ups — one file per puzzle. |
| `pitches/` | Stock pitch slides and written theses. |
| `resources/` | Reading list, TMUA materials, study notes. |
| `tools/` | Code written by members. |
| `leaderboard/` | Current standings, updated weekly. |

Each folder holds a `.gitkeep` so it tracks in git while empty — delete it once the
folder has real content.
